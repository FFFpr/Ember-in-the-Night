# Kelly 房间拟合清单

> **本文件：** `art_style_demo/07_kelly_room/` 的验收判据，由定稿样例 `fp_idle.png` 翻译而来，已通过。基准画幅与明暗判据见 [`art-style.md`](../../../docs/tech/art-style.md)，像素约束见 [`pixel-art-standard.md`](../../../docs/tech/pixel-art-standard.md)，本文件不复述。

坐标在基准画幅上归一化：左上原点，`x, y ∈ [0, 1]`，`w`/`h` 是占画面宽/高的比例。未注明的容差为 ±0.03。

细则：

- 白板由双链吊在玻璃上方的横梁上，两行字，字高 0.032。
- 金币海冠线不齐：峰在 `x ≈ 0.36` 处 `y ≈ 0.42`，两端落到 `y ≈ 0.55`，基线 `y ≈ 0.635`。玻璃开口的上半保持空且暗，投资时金币从这里落入。
- 公式与等号是黑油笔笔迹，写在玻璃上；公式区域的玻璃比其余部分更磨砂、更不透明。
- 摇杆球头顶 `y ≈ 0.545`，底座落在地板上。
- 壁灯点亮，焰心 (0.068, 0.405)，是全幅唯一最亮处。

## 尺度

| 项 | 目标 |
|----|------|
| 金币海单枚金币 | 侧视，直径约 0.012 画面宽，成柱 5–15 枚高 |
| 地面散币 | 俯视，直径约 0.022 画面宽 |
| 天花板 | 不入画，画面顶边止于玻璃上方的横梁 |
| 地板 | 长板朝镜头收敛，不是错缝短砖 |

## 房屋结构

玻璃四周必须读出木结构：上方一根横梁贯通画面，左右各一根立柱夹住玻璃，玻璃下方是铆接铁裙板，右墙有一扇冷光小窗。

## 明暗

判据与量法见 `art-style.md`。定稿样例的实测值作为目标参考：

| 项 | 样例实测 |
|----|----------|
| 全幅均值 | 34.8 |
| 边缘条带均值 | 28.8 |
| 全幅 P90 | 76.0 |
| 边缘 / P90 | 0.38 |

为让文字可读而补的光必须局部（贴着白板与公式的小范围光），不要抬全局环境光。

## 1:1 可读

基准画幅 1:1 下必须能读出：白板两行；投币箱正面 `已投/总数`；公式两行；揭开贴纸后显示的应投金币数。

## 框选态

同一房间。被选金币聚成一簇跟随光标，簇上方显示数量，字高 0.040 ±0.010。参考 `fp_select.png`（旧 3:2 画幅，只作数量显示的参考，构图以 `fp_idle.png` 为准）。

## 与旧文字的裁决

`07_kelly_room/README.md` 写「出币口长度大致占据整个视角的 1/3」。定稿样例与本清单为 0.220，按定稿样例执行。
