# Kelly 房间参考图

AI 构图 / 道具 lookdev，**不是**可进场景的像素素材。正式精灵见 `Aseprite-User/export/`。

`fp_idle.png` 是定稿样例，画幅 1536×864（16:9，与基准画幅同比例）。它决定物体、分布、画面位置与占比、比例、明暗结构；材质与色数不由它决定。可判定的验收判据在 [`fit_list.md`](fit_list.md)——动场景前先读那份，不要直接对着图估。

|------|------|
| `fp_idle.png` | **定稿样例**，主视角待机 |
| `fit_list.md` | 从定稿样例翻译出的验收判据（已通过） |
| `fp_select.png` | 框选后鼠标旁显示数量；旧 3:2 画幅，只作数量显示的参考 |
| `fp_idle_legacy_3x2.png` | 上一版 3:2 待机图，已被取代，仅作氛围参考 |
