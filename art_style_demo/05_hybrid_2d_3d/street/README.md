# Street — hybrid 2D + 3D

## Goal

2D street day→night loop; hybrid only as a **small accent** (e.g. 3D hanging sign or lantern).

## Day → night (20 s)

| Time | Look |
|------|------|
| 0–10 s | 2D day plate + bright modulate |
| 10–20 s | 2D night wash; 3D accent picks up night emissive/light |

Do not rebuild the whole street in 3D for this demo.
