# Workshop — isometric

## Goal

Readable iso interior focused on forge and anvil (close locked camera).

## Required set dressing

- Forge and anvil as multi-tile or tall sprites
- Walkable floor tiles; walls that do not hide the bench
- Props snapped to grid: bellows, rack, barrel, crates, horseshoes

## Implementation sketch

- Locked iso camera centered on the work cells.
- “First-person” = player feels stationed at the anvil cell looking across to the forge.
- Minimal interaction grid later; look-dev can be static.
