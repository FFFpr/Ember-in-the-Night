# Street — 2D lighting

## Goal

Same street framing as other approaches; day/night driven by the **light setup**.

## Day → night (20 s)

| Time | Look |
|------|------|
| 0–10 s | Soft directional / bright ambient; shadows short or mild |
| 10–20 s | Ambient drops; shop windows + street lamps + forge spill become keys |

At t=10 s, enable night lights (and optionally dim/disable the day directional). Keep camera fixed.
