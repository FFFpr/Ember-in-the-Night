# 07 — Kelly 房间

独立小场景，在 demo 当中，包含独立的脚本。用 F6 打开 `kelly_room.tscn`。不要改 `project.godot` 的主场景。

构图对照：[`../references/kelly_room/`](../references/kelly_room/)。像素道具只从 `Aseprite-User/export/props/kelly_room/` 读取；缺图时用锻夜色灰盒。

## 游戏介绍

基于 kelly 公式模拟赌博游戏。游戏以【轮】为单位进行：第一轮中，玩家只有一枚金币，此时投资的成功率是 100%，回报率是 1，及投入一个金币，利息是一个金币，连本带息会返回两个金币。此后每轮的投资成功率和回报倍率都是随机的。

每轮是这样进行的：玩家按住鼠标左键，拖拽并松手会在矩形范围内框选一些金币，金币被聚集到鼠标周围，鼠标周围显示出框选的金币数量。当鼠标在其他位置再次点击鼠标左键时，金币会从鼠标的位置自由掉落；当鼠标在投币箱的位置上时，投币箱有一个放大的效果，同时加上黑色描边，表示此时松手是投币。当松手时，金币被吸入投币箱的投币口。不能从投币箱内取回。然后投币口上显示出已投币的数量。玩家可以反复执行这一行为，只要还有金币。

当玩家点击投币箱旁边的摇杆时，进行投资，投币箱中的所有金币被清空，按照投资成功率进行随机。如果成功，从出币口连本带息地弹射出对应数量的金币，否则没有任何回报，连本金都丢失。这样算【一轮】。如果玩家在游戏中亏损了所有的金币，出币口会在【下一轮】弹出一枚金币。只要玩家手上只有一枚金币，那投资的成功率和回报率就永远和【第一轮】时的数值一致。

画面表现上，玻璃墙背后的金币是无限堆叠的“市场”，当投资开始时，玻璃墙背后的上面会有对应数量的金币掉落下来。玻璃墙前面的部分表示玩家持有的金币数量，也是玩家可以经过框选选中的金币对象。

每轮的总金币数是不变的，即使金币进入了投币箱，这部分的金币也属于未投资的部分。所以每轮中 kelly 的结果是不变的（总金币不变，倍率不变，概率不变）。

## 场景描述

这是一个实木板搭建的房间，视角在房间内部。视角右侧靠墙位置的地板上，放着一个【投币箱】，旁边有一个【摇杆】，点击以后有一个向下拉的动画。投币箱上有黑色油性笔笔迹，显示出本轮投币数量和玩家拥有的总金币数，以【已投币数/总金币数】的形式出现。

在视角的正面，是一整面玻璃墙，玻璃墙底部靠近地板的位置有一个横条状的【出币口】，长度大致占据整个视角的 1/3，出币口有一个阀门，平时处于关闭状态，只有出币时才打开。在玻璃墙的背后（仍然是屋子的内部）被非常多的【金币】填满，金币堆叠在玻璃的后面。

在玻璃墙的正中央，靠近视角上侧的位置，有一块白板，上面用黑色的油笔字体写着给玩家的信息，有几种信息，会在不同情况下出现：【1.当天的投资回报倍率和投资成功的概率；2.投资成功或者失败】。在玻璃墙的左侧上也会有黑色油性笔写着：Kelly 公式（待遇投资回报倍率和投资成功概率的公式，投资失败则全部亏损），其中回报倍率的数值和投资成功概率的数值由具体数字填充。公式的 = 等号后面盖着一张【贴纸】，点击后播放贴纸被揭掉的动画，然后在贴纸原本的位置上显示出计算后的金币数（Kelly 公式本身计算出的比例和玩家拥有的总金币数计算得到本次应该投资的金币数）。贴纸点击后撕掉，再次点击整数，贴回贴纸。
