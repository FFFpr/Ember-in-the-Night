# Shared look-dev assets

## `placeholders/`

Runtime builders for workshop/street composition (`workshop_layout.gd`, `street_layout.gd`). Approaches `01` and `02` share these so framing stays comparable.

## `imported/`

Free-store, **non-AI**, open-licensed packs used by the compare pass:

| Pack | License | Use |
|------|---------|-----|
| `polyhaven_textures/` | CC0 | Wood / stone / cobble / metal / roof / plaster diffuse maps |
| `kenney_background_elements_remastered/` | CC0 | Street houses, towers, sun/moon, clouds |
| `kenney_smoke_particles/` | CC0 | Forge flash + smoke particle textures |

Each pack folder includes `LICENSE.txt` and/or `CREDITS.txt`. Do not use AI files from `art_style_demo/references/` as scene art.
