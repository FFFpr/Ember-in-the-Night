# Shared look-dev assets

## `placeholders/`

Runtime builders for workshop/street composition. Approaches `01` and `02` share these so framing stays comparable.

**Compare-pass rule:** hero props and building masses are pack `Sprite2D`s (authored silhouettes). Solid/textured coded polygons are limited to sky wash, floor/wall texture washes, and soft glow overlays.
