# 像素绘图标准

> **本文件：** 像素 2D 资产的验收约束（画布、色数、色块、调色板）。不依赖 look-dev 场景。Godot 侧受光 / 投影 / Nearest 见 [`art-style.md`](art-style.md)。

量的是**不透明像素**（alpha ≥ 16）。透明底不计入 `A` 与 `C`。

## 色数

独特色数随不透明像素数的**平方根**增长，不是随面积线性增长。对本仓库 LPC 道具 + `Aseprite-User` 精灵（n=31）拟合：

```text
C ≈ 0.19 √A
```

`C` = 不透明像素上的独特 RGBA 色数，`A` = 不透明像素数。实测带：`C / √A` 的 10–90 分位约为 **0.09–0.38**（中位 0.24）。

```text
C_max = min(表内上限, max(8, round(0.35 √A)))
```

| 画布 | 上限 |
|------|------|
| 16×16 / 16×32 | 8 |
| 32×32 / 32×48 | 12–16 |
| 48×48 | 16 |
| 64×64 | 20 |
| 320×180 整幅（仅对照，不进玩法） | 32 |

颜色必须来自下文锻夜板。`C_max` 限制从板上抽几颗，不授权新色相。只卡色数不够：量化插画可以色数过关，色块仍然碎。

## 画布

| 层级 | 画布 (px) | 用途 |
|------|-----------|------|
| 图标 / 小道具 | 16×16 或 32×32 | UI、马蹄铁、锭 |
| 手持 / 角色 | **48×48**（角色也可 32×48） | 锤子、主角四向 |
| 场景道具 | 64×48 或 64×64 | 铁砧、桶 |
| 大型道具 | 96×80 | 锻炉立面 |
| 对照（不进玩法） | 320×180 | 禁止当正式场景贴图 |

整数倍缩放。同一层级不要混用未列表尺寸。

## 色块

对**索引色成品**（不要先量化再量插画）。色块 = 4-连通同色连通域。

| 项 | 英雄道具（锤、砧、角色） | 说明 |
|----|--------------------------|------|
| 碎点比 | **≤ 0.30** | 面积 ≤2 的色块 / 全部色块 |
| 平均色块 | **≥ 8** px | 过小 = 噪点；过大且全是矩形 = 未画材料 |
| 可读色块数（面积 ≥4） | 大约 `0.8–2.0 × √A` | 随 √A 涨，不随 A 涨 |

## 锻夜板

每张图是下表的**子集**。禁止第 N+1 颗只此一次的颜色。

| 名 | RGB | 用途 |
|----|-----|------|
| outline | 28, 22, 26 | 描边（不用纯黑） |
| metal_d / metal_m / metal_l / metal_hi | 48,46,58 / 92,90,102 / 168,158,148 / 232,214,176 | 金属 |
| wood_d / wood_m / wood_l | 62,38,28 / 118,72,42 / 176,118,62 | 木 |
| wrap | 86, 58, 44 | 皮缠、握把 |
| stone_d / stone_m / stone_l | 42,44,52 / 74,72,78 / 112,104,96 | 砖石 |
| ember_d / ember_m / ember_l | 148,48,22 / 220,96,28 / 255,186,72 | 炉口 |
| night / night_d | 46,78,118 / 22,32,52 | 水面、夜色凹 |
| skin_m / leather | 196,132,96 / 92,52,36 | 皮肤、皮带 |

头发 / 围裙从 `outline`、`leather`、`wood_*` 抽，不要另开红。

| 材料 | 台阶（深 → 亮） | 最多用 |
|------|-----------------|--------|
| 金属 | metal_d → metal_m → metal_l → metal_hi | 4（小图标可 3） |
| 木 | wood_d → wood_m → wood_l | 3 |
| 石 | stone_d → stone_m → stone_l | 3 |
| 余烬 | ember_d → ember_m → ember_l | 3，仅炉口 |
| 皮 / 握把 | leather 或 wrap，必要时 + wood_d | 2 |
| 皮肤 | skin_m，暗部用 leather | 2 |

1px 描边用 `outline`。禁止抖动、禁止抗锯齿。默认左上光；**每个物件只有一处最亮**（`metal_hi` 或 `ember_l`，不要更亮的白）。

## 可读性

同时满足：剪影缩小 50% 或改成纯黑仍能认出物件；同色成面而非盐胡椒；材料用上表斜坡；与同层级其他图画布、锚点一致。

## 制作

1. 索引色，只用锻夜板。画布选自上表，`C_max` 按公式。
2. 剪影 → 材料块（表内斜坡）→ 一处高光。禁止插画缩小量化当交付。
3. 验收：`C ≤ C_max`、碎点比、平均色块、纯黑剪影。

向 [Aseprite-User](https://github.com/FFFpr/Aseprite-User) 开 issue 时填写画布、`C_max`、用到的色名。模板见 [`art-style.md`](art-style.md)。
